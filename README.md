# Nexa Vault

Nexa Vault is a lightweight DeFi and open finance smart contract project built on OPN Testnet.

## Overview

Nexa Vault explores decentralized financial interaction through smart contracts and transparent blockchain execution.

## Features

- Permissionless participation
- Smart contract deployment
- Open financial interaction
- EVM compatibility

## Technology Stack

- Solidity
- Remix IDE
- MetaMask
- OPN Testnet

## Deployment

Successfully compiled and deployed on OPN Testnet.

## Future Vision

Expand open and transparent financial infrastructure.
